# PowerTools Resource Pack – Minecraft Java 1.21.11

1. Copy `PowerTools-ResourcePack.zip` into `.minecraft/resourcepacks` (or use the extracted folder).
2. Enable **PowerTools – Blitz Items** in Minecraft's Resource Packs menu.
3. Join a server with the PowerTools plugin and receive an item with `/power items give <player> <axe|drill|cellx|bucket>`.

The pack uses the 1.21.4+ item model definition format and is set to resource-pack format 75 for 1.21.11.
